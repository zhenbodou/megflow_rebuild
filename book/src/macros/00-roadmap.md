# Rust 宏完整教程：从第一次调用到独立维护

这是一条连续的学习路线，可以脱离 MegFlow 的运行时章节先学。你只需要先会变量、函数、结构体、泛型和 trait；不熟悉时先看 [Rust 复习](../part1/ch01-rust-review.md) 与 [泛型和 trait](../part1/ch02-traits-dyn.md)。这里的“专家实践”指能设计语法、解释展开、维护兼容性并用证据验证行为，不意味着看完就自动精通。

## 怎样学

每课按“读输入 → 手写预期输出 → 运行代码 → 故意改错 → 完成练习”的顺序。不要先背 syn 的所有类型。遇到一个需求，再学习表达它的 AST 节点。

| 阶段 | 课程 | 完成后你能做什么 |
| --- | --- | --- |
| 入门 | [1 宏与展开](01-basics.md)、[2 声明宏进阶](02-declarative.md) | 解释匹配器、重复、递归、片段转发和作用域 |
| 基础开发 | [3 过程宏](03-procedural.md)、[4 三件套](04-tokens.md)、[5 三种宏](05-three-forms.md) | 从空目录创建过程宏 crate，并运行下游程序 |
| 复杂实现 | [6 泛型与属性](06-generics.md)、[7 组合与路径](07-composition.md) | 生成正确约束，处理属性，识别名字解析和 AST 改写边界 |
| 工程维护 | [8 诊断与测试](08-engineering.md)、[9 发布维护](09-maintenance.md) | 分辨编译与运行错误，设计兼容性和性能验收 |
| 项目应用 | [10 MegFlow 实战](10-megflow.md) | 对照原版宏清单，按业务语义验证生成代码 |

正文中的完整源码通过 mdBook 的 include 引用实际文件，修代码后书中同步更新。标记 `ignore` 的片段需要所属工程上下文，不代表已经由 rustdoc 自动测试；实际验证命令会单独列出。

所有命令默认从仓库根目录执行，除非代码块明确写了 `cd`。一键检查课程：

```bash
python3 scripts/check_macro_course.py
```

它运行声明宏、Token 和注册表示例，构建三种过程宏的独立阶段工程，并测试进阶 Describe。失败时先看第一个失败命令，避免把网络下载失败误认为 Rust 语法错误。

## 工具各管一段流程

`proc_macro` 是标准库提供的编译器入口；`proc-macro2` 让 token 操作能在普通函数和测试里使用；`syn` 将 token 解析成结构化数据；`quote` 将数据填回代码模板。`trybuild` 检查下游代码的编译结果；`inventory` 负责项目注册机制，不能替代语法解析。第 4、8、10 课分别动手使用这些 crate。

进阶选型还会涉及 `proc-macro-crate`、`darling`、`prettyplease` 和 `cargo-expand`。第 9 课解释何时需要它们、怎样验证；本课程没有为了凑依赖把所有工具装进项目。

## 最终自测

不看实现，解释为什么 derive 不能给原结构体增加字段；给 Describe 加一个辅助属性；让错误定位到属性而非宏定义；证明跳过的泛型字段不需要 Display；解释依赖改名为何会使生成路径失效；最后为 Actor 的错误收尾写行为测试。能完成这些，再独立扩展 MegFlow 的原版端口语法。
